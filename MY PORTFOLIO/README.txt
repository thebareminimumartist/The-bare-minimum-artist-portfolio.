# 3D Artist Portfolio Template

This is a structure-first portfolio template designed for a 3D artist working with Blender screenshots, viewport captures, final renders, personal projects, and freelance/client work.

## Files

- `index.html` — portfolio structure and placeholder content
- `style.css` — all visual styling and responsive behavior
- `assets/` — put your images, résumé PDF and other media here

## What to customise first

1. Replace `YOUR NAME`, location, email and social links.
2. Replace every `assets/...` image with your own renders/screenshots.
3. Change project names, software and dates.
4. Add your actual résumé PDF.
5. Remove sections you do not need.

The design deliberately leaves large visual areas so the artwork is the main focus.
